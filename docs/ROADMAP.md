# Roadmap

## 0.4.x：公开 Alpha

- 可复现构建、通用 systemd 运行配置和开源治理。
- 完成真实 Forge 单机服迁移验证。
- 增加安装前 doctor 与配置错误的通俗解释。

## 0.5：登录与通知

- WebAuthn Passkey、恢复代码和活跃会话管理。
- 可选 Webhook/邮件通知，默认只发送最小脱敏摘要。
- 备份失败、磁盘不足、连续崩服和服务离线规则。

## 0.6：引导式诊断

- “朋友进不来”“服务器很卡”“刚才崩服了”等可解释诊断流程。
- 每一步展示证据、风险、是否停服和回滚方式。
- AI 不可用时仍可运行确定性诊断。

## 1.0：稳定单机版

- 安装、更新、回滚和灾备流程在多个发行版与加载器组合上验收。
- screen 之外至少一种受限控制台适配器。
- 稳定迁移政策、长期支持说明和完整管理员手册。

不在单机版路线图：多租户、计费、Kubernetes、游戏服务器销售、自动升级大型整合包或自动修改公网网络。
